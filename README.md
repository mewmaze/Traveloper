## ⚡ 주요 기능

### ✈️ 여행 계획 관리

- **여행 생성**: 타입 안전한 폼 검증 (Zod + React Hook Form)
- **국가 선택**: 국가 API 연동으로 여행지 선택 기능

### 💰 실시간 환율 & 지출 관리

- **자동 환율 계산**: 국가 선택 시 실시간 환율 자동 적용
- **지출 내역 관리**: 전체/날짜별 지출 내역 조회
- **서버 액션**: Next.js Server Actions로 최적화된 데이터 처리
